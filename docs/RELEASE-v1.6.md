WWave меняет настоящую яркость TCL по ежедневному расписанию. В приложении можно выбрать дневной и ночной уровни, время переключения, проверить режимы и отключить автоматизацию с возвратом дневной яркости.

В этой версии: пастельный WW-логотип без квадрата и повторной подписи в шапке, светлый экран настроек, собственный ключ для чистой установки и кнопка первичного подключения. Расписание по умолчанию — 21:00–09:00, день 30/100, ночь 10/100.

Скачайте **WWave-1.6.apk** ниже. Обновление поверх предыдущей версии сохраняет настройки и авторизацию. Для чистой установки нужна сетевая отладка ADB на телевизоре (порт 5555), затем «Подключение» → «Всегда разрешать» → «Разрешить».

Проверено на TCL G10/C6KS с Android 12 и русским меню: авторизация чистой установки, обновление, цикл 30→10→30 через таймеры, отключение с отменой всех таймеров и остановкой службы. Подробности — в [проверках](https://github.com/natural0101/wwave/blob/main/docs/VERIFICATION.md).

Предварительный релиз: полная перезагрузка, HDMI/HDR и другие прошивки пока не проверены. При переключении приложение открывает штатное меню примерно на 10–20 секунд. Чужие ключи ADB и закрытый ключ подписи в APK/репозиторий не включены.

Рядом с APK опубликован файл SHA-256 для проверки скачивания.
