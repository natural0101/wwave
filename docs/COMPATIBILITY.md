# Совместимость WWave 1.9

WWave управляет аппаратной подсветкой. Совместимость определяется доступным интерфейсом прошивки, а не только названием марки. Эта версия не заявляет универсальную поддержку телевизоров.

| Устройство / платформа | Статус | Основание |
|---|---|---|
| TCL G10 / C6KS, Android 12 | Проверено на реальном ТВ | TCL PQ SDK, изменение 30→31→30, обязательное чтение результата |
| Другие TCL/iFFALCON с `com.tcl.tv.pq.TvBacklightManager` | Кандидаты на поддержку | Автоматическое определение класса, методов и чтения; запись подтверждается отдельно на каждой прошивке |
| TCL/iFFALCON с `com.tcl.tvmanager.TTvPictureManager` | Добавлен адаптер; железо не проверено | Контракт getInstance(Context), getBacklight(): int, setBacklight(int): void/boolean найден в собственной библиотеке настроек TCL; тесты на синтетическом SDK |
| Sony BRAVIA с REST v1.0 | Экспериментальный адаптер; без испытаний на Sony | Проверка доступных методов, brightness и его родной шкалы; требуется IP control и доступ к API с самого ТВ |
| Hisense DS с REST API | Экспериментальный адаптер; без испытаний на Hisense | Официальные get/setBackLightValue; не заявляет поддержку бытовых Hisense / VIDAA |
| Philips / Xiaomi / другие Android TV и приставки | Нет реализованного адаптера | Нет проверенного интерфейса подсветки; приложение показывает несовместимость |
| Tizen / webOS | APK не предназначен для этих платформ | Это не Android-приложения |

## Что проверяет приложение

1. Ищет два известных TCL-контракта через штатный загрузчик классов. Библиотеки объявлены optional, поэтому их отсутствие не должно мешать установке Android APK.
2. Проверяет типы методов, наличие именованных режимов CURRENT/EXECUTE_SAVE и допустимое чтение 0–100. Обнаружение ничего не записывает.
3. В «Совместимости» различает чтение доступного интерфейса и подтверждённое изменение с обратным чтением. Подтверждение записи привязано к Build.FINGERPRINT и выбранному интерфейсу.
4. После ошибки записи проверяет исходный уровень и при необходимости пытается вернуть его тем же интерфейсом. При неудаче явно сообщает, что восстановление не подтверждено. Другой интерфейс после неудачной записи не вызывается.
5. При отсутствии поддержки, отказе службы или таймеров отменяет расписание. Фильтры, системное `screen_brightness`, root, произвольные Binder-транзакции и открытие меню не используются.

## Экран и версии Android

- Установка: min SDK 26 (Android 8), target SDK 32. Фактически проверен Android 12. Другие версии пока не сертифицированы испытаниями.
- Java-only APK не включает нативных библиотек и не фиксирует ABI процессора.
- При ширине менее 800dp карточки становятся вертикальными. ScrollView и высота по содержимому позволяют добраться до нижних кнопок пультом.
- На реальном TCL проверены обычный экран 1920×1080 и отдельная тестовая Activity с конфигурацией 640×360dp/480dpi. Это проверка двух вариантов компоновки на одном ТВ, не испытание отдельного HD/4K телевизора.
- Для Android 12+ проверяется разрешение точных таймеров; в диалоге предусмотрен переход в соответствующий системный раздел. Отказ фонового запуска службы не оставляет ложного «включено».
- На API 33+ указан флаг NOT_EXPORTED для динамического приёмника. Эта ветвь скомпилирована, но на Android 13+ не запускалась.

## Что ещё нужно для заявления о широкой поддержке

Для каждой новой модели: модель и прошивка → чтение → небольшое изменение и возврат → оба таймера → отключение → перезагрузка → сон/пробуждение → HDMI/SDR/HDR-профили. До выполнения этих сценариев модель остаётся кандидатом, даже если обнаружение интерфейса прошло.

Общий Media Quality framework появился в Android TV 16, но глобальные профили требуют системных разрешений; наличие Android 16 само по себе не даёт WWave доступа к общей подсветке. Источник: https://developer.android.com/training/tv/mqf

## Расширение в версии 1.9

Sony и Hisense выбираются вручную при отключённом расписании. Подключение ограничено самим ТВ (127.0.0.1). PSK зашифрован Android Keystore. У Sony учитываются min/max/step; проверяется точное родное значение. При ошибке подтверждение записи сбрасывается. Родная шкала и текущий уровень показаны в диалоге. Подробности, первичные источники и ограничения профилей: [REVIEW.md](REVIEW.md).
