# WWave

Real TCL TV backlight on a daily schedule. Remote-friendly settings and a pastel WW monogram.

**[Download the signed APK](https://github.com/natural0101/wwave/releases/download/v1.7/WWave-1.7.apk)** · [Release notes](https://github.com/natural0101/wwave/releases/tag/v1.7)

![WWave settings](docs/settings.png)

## Что делает приложение

WWave меняет настоящую подсветку через штатную библиотеку TCL **без открытия меню и переключения текущего приложения**. Ночной режим по умолчанию: **21:00–09:00**, ночью **10/100**, днём **30/100**. Время и уровни редактируются на экране настроек.

Есть переключатель расписания, проверка ночного уровня, возврат дневного и кнопка **«Отключить и вернуть дневную яркость»**. Отключение отменяет таймеры и останавливает службу после возврата дневного уровня.

## Совместимость и установка

Проверено на **TCL G10 / C6KS, Android 12**. Минимальная версия установки — Android 8; другие прошивки не проверены. Нужна установленная библиотека `com.tcl.tv.display`, предоставляющая приложению доступ к подсветке. При отсутствии библиотеки или отказе доступа WWave показывает ошибку; меню автоматически не открывается.

1. Установите `WWave-1.7.apk` на телевизор, поверх прежней версии для сохранения настроек.
2. Откройте WWave и нажмите **«Проверить доступ»**. Проверка прочитает текущую подсветку, без изменения уровня.
3. Выберите дневную/ночную яркость и время, сохраните настройки, проверьте оба режима и включите расписание.

**Для работы версии 1.7 ADB, компьютер и сеть не нужны.** APK не содержит ADB-клиента и не запрашивает разрешение INTERNET. ADB можно использовать только как способ установки APK или диагностики с компьютера.

Изменяется текущий профиль изображения (`EN_APPLY_CURRENT`). Переключение источника, отдельные HDMI/HDR-профили, полная перезагрузка и другие прошивки не проверены. Выключенный телевизор приложение не включает.

Если FLauncher не добавил плитку: **Settings → Applications → TV Applications → WWave → «+» → TV Applications**.

## Сборка на Windows

Нужны JDK 17, Android SDK Platform 32 и Build Tools 34.0.0. Ресурсы включены в репозиторий; библиотека TCL берётся с самого телевизора, её бинарник не распространяется в APK.

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-17'
$env:ANDROID_SDK_ROOT = 'C:\path\to\Android\Sdk'
.\build.ps1 -Unsigned
```

Для подписанного APK задайте `WW_KEYSTORE` и `WW_KEYSTORE_PASSWORD` в окружении. Закрытый ключ не публикуется; APK с другой подписью не обновит официальную установку.

Для упаковки размеров иконки: `python scripts/prepare_assets.py` (Pillow).

## Устройство

- `MainActivity` — настройки и проверка доступа.
- `TclBrightness` — `TvBacklightManager.getBacklight()` / `setBacklight(EN_APPLY_CURRENT, level, EN_TCL_ACT_EXEC_SAVE)` через установленную библиотеку TCL; чтение результата обязательно.
- `ScheduleService`, `AlarmReceiver`, `BootReceiver` — расписание и применение уровня.
- `ControlReceiver` — диагностика, защищённая системным разрешением `android.permission.DUMP`.

Root, сервер, аккаунт и облачная синхронизация не требуются.
